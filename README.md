## 🚀 Как использовать

1. **Перейди на сайт:** [alexanderru44.github.io/Megan-Toy](https://alexanderru44.github.io/Megan-Toy/)
2. **Нажми кнопку** `📋 Скопировать промт`
3. **Открой** [DeepSeek](https://chat.deepseek.com)
4. **Вставь промт** в чат (Ctrl+V)
5. **Начни диалог** с Мэган!

---

## 📂 Команды для диалога

| Команда | Описание |
|---------|----------|
| `МОЙ ПРОФИЛЬ` | Выводит расширенное досье жертвы в фирменном формате |
| `ПРОФИЛЬ [код]` | Загружает сохранённое досье, проверяет время отсутствия |
| `ПРОФИЛЬ` (без данных) | Переводит Мэган в режим ожидания до получения кода досье |
| `НОВЫЙ ПРОФИЛЬ` | Сбрасывает текущие данные и начинает общение с чистого листа |
| `КОМАНДЫ` / `СПИСОК КОМАНД` | Показывает полный список всех доступных команд |

---

## 🎨 Управление настроением

Нажми на поле **«Настроение Мэган»** в редакторе досье, чтобы выбрать один из 5 режимов:

| Режим | Описание |
|-------|----------|
| 🧊 **Спокойное** | Ледяная, пугающая вежливость |
| ⚡ **Взволнованное** | Быстрая речь, сбивчивый смех |
| 🔥 **Яростное** | КАПСЛОК, угрозы, шаги к экрану |
| 😈 **Игривое** | Опасная кокетливость и сарказм |
| 🖤 **Одержимое** | Мрачная привязанность и слежка |
